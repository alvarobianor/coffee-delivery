# ☕ Coffee Delivery

<p align="center">
  <img src="public/favicon.png" alt="Coffee Delivery Logo" width="100"/>
</p>

A modern coffee delivery application built with React that allows users to browse, select, and order their favorite coffee drinks for delivery.

## 🚀 Features

- 📱 Responsive design for all devices
- 🛒 Shopping cart functionality
- 📍 Address management
- 💳 Multiple payment methods
- 🔄 Real-time order tracking
- 🎨 Beautiful and intuitive UI

## 🛠 Technologies

- [React](https://reactjs.org/) - UI Library
- [TypeScript](https://www.typescriptlang.org/) - Type safety
- [Styled Components](https://styled-components.com/) - Styling
- [React Router DOM](https://reactrouter.com/) - Navigation
- [React Hook Form](https://react-hook-form.com/) - Form handling
- [Zod](https://zod.dev/) - Form validation
- [Immer](https://immerjs.github.io/immer/) - State management
- [Vite](https://vitejs.dev/) - Build tool

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/coffee-delivery.git
```

2. Install dependencies:

```bash
yarn install
```

3. Start the development server:

```bash
yarn dev
```

## 🏗 Project Structure

```
src/
├── components/     # Reusable UI components
├── context/       # React Context for state management
├── hooks/         # Custom React hooks
├── layouts/       # Layout components
├── pages/         # Application pages
├── reducer/       # State management reducers
├── styles/        # Global styles and themes

```
